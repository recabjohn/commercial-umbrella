### 3.1 Dependency chains between fields (from the Keys sheet and Policy fields)
- Entity Type (Commercial/Government) -> Legal Entity, Major Industry Group, Monoline Policy Type, Package Policy Type, Risk Type.
- Major Industry Group -> Predominant Activity -> Class Description and Class Code.
- Monoline Policy Type -> Monoline Coverage Type; Package Policy Type -> Package Coverage Type.
- Coverage limit and deductible lists depend on the coverage's **Included** switch (key name 'Included').
